# 更多繁殖优化（MoreBreedingOptimize）

欢迎使用 **更多繁殖优化**！本手册介绍模组的主要物品与玩法。

## 主要玩法

- **末地烛配种**：手持末地烛右键动物，可触发动物繁殖；在末地烛上快速潜行可能触发掉落（概率可在配置中调整）。
- **化学合成**：使用试管、烧杯、培养皿等器具合成各类药剂。

## 物品一览

- **春药（sm）**：让动物进入**发情**状态的药剂。
- **春药注射器（smt）**：装填春药后注射给动物。
- **空注射器（nullsyringe）**：空的注射器，用于装填药剂。
- **生长激素（ghw）** / **生长激素注射器（gh）**：促进动物成长。
- **抽血针筒（bts）**：对动物抽血取样。
- **丘比特之弓（lovebow）**：射出爱神之箭，触发亲吻事件。
- **野生狗奶（dogm）**：特殊饮品。
- **日本进口生可乐（jnhc）**：喝下后获得**宾州强化**效果；拥有该效果时，在聊天框输入 `@滨州 你想说的话` 可与宾州对话。
- **更多繁殖优化手册（sbook）**：就是你现在看到的这本书。

## 效果一览

- **发情（lust）**：让动物进入发情状态，便于配种。
- **永恒（eternal）**：持续生效的增益效果。
- **宾州强化（bzstronger）**：喝下日本进口生可乐后获得，期间头顶会生成光源，并解锁与宾州的聊天对话。

## 配置

模组的推力强度、掉落概率、意外死亡概率、亲吻检测距离等均可在 `morebo-common.toml` 中调整。
