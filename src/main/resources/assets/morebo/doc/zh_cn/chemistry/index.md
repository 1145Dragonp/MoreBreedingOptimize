# 化学书

欢迎来到 **化学合成** 手册！这里介绍化学器具、配方与化学物质。

## 器具

- ![试管](item:morebo:test_tube) **试管（test_tube）**：化学合成的基础器具。
  - 手持试管时，另一只手拿**桶 / 药水**右键 → 装入**溶液**；
  - 另一只手拿其他物品右键 → 装入**固体**；
  - **潜行 + 右键** → 取出内容物（溶液会倒出为药水）；
  - 内容物匹配到配方时自动合成，成功提示「合成成功」。

## 配方一览

试管内装入对应材料即自动合成（标注「需溶液」的配方要先装入溶液）：

- **春药（sm）**：粉红染料 + 糖 + 金胡萝卜（需溶液）→ ![春药](item:morebo:sm) ×16
- **生长激素（ghw）**：金胡萝卜 + 闪烁的西瓜片 + 红石粉（需溶液）→ ![生长激素](item:morebo:ghw) ×32
- **放射性元素X（rex）**：铁锭 + 煤炭 + 火药 + 烈焰粉（无需溶液）→ ![放射性元素X](item:morebo:rex) ×9

## 化学物质

- ![放射性元素X](item:morebo:rex) **放射性元素X（rex）**：由化学合成得到的稀有物质
