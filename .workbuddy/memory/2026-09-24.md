# 2026-09-24

- 项目已从 BreedMovement (modid: breedmovement) 迭代为 MoreBreedingOptimize (modid: morebo)，包名 MoreBreedingOptimize，版本 1.0.5。src 下新增大量 MD 子包（IVF 试管受精、SM、DOGM、JNHC、生长激素、化学合成等）。
- 修复崩溃：创造模式物品栏悬停 BTS 物品 tooltip 时 NPE `Trying to access unbound value: ResourceKey[minecraft:data_component_type / morebo:source_entity]`。根因是 `MainClass` 构造函数从未调用 `ModDataComponents.register(modEventBus)`，SOURCE_ENTITY 的 DeferredHolder 未绑定。修复：在 IVFITEM.register 之后补一行 `MoreBreedingOptimize.MD.IVF.ModDataComponents.register(modEventBus)`。
- 经验：NeoForge 中每个 DeferredRegister（含 DeferredRegister.DataComponents）都必须显式注册到 modEventBus，漏一个就是"unbound value" NPE。ChemistryDataComponents 是在 ChemistryItem.register 内部注册的，ModDataComponents 没有类似入口，容易漏。
- BTS（抽血试管）三问题修复：① 纹理不切换——bts.json 有 custom_model_data:1 的 override（切 bts1 装血纹理）但代码从未设置 CustomModelData 组件，现抽血成功时 `bts.set(DataComponents.CUSTOM_MODEL_DATA, new CustomModelData(1))`；② tooltip 只对带 source_entity 组件的 BTS 显示，创造标签页拿的空瓶没有组件（属设计行为），现空瓶显示"空样本"提示；③ "点击没反应"难排查——BTSHandler 原本无日志，现加了抽血跳过原因（手持物品不对/目标非成年）与成功日志。
- 注意 EventBusSubscriber 的正确 import 是 `net.neoforged.fml.common.EventBusSubscriber`（不带 .neoforge 前缀）。
