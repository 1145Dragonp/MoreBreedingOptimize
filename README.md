# MoreBreedingOptimize（更多繁殖优化）

一个面向 Minecraft 1.21.1 / NeoForge 的动物繁殖玩法扩展模组，把原版枯燥的"喂食 → 等待 → 生崽"变得更有趣、更高效，也更有"节目效果"。

- **Mod ID**: `morebo`
- **支持版本**: Minecraft 1.21.1 · NeoForge 21.1.244 · Java 21
- **作者**: Mrmagicdragon
- **语言**: 简体中文 / English

---

##  功能特性

###  繁殖物理特效（Breeding Physics）

- 动物进入恋爱模式后，两只**同类**靠近到一定距离（默认 2 格）会触发"亲吻"事件，并**互相弹开**——繁殖不再只是原地冒爱心。
- 繁殖瞬间双方会获得相反方向的推力，充满戏剧性。
- 繁殖时有概率（默认 5%）掉落**水桶 / 牛奶桶**。
- 小概率（默认 0.5%）发生"意外"，掉落一根**末地烛**（附近动物会冒出大量爱心粒子）。

###  末地烛催生（End Rod Breeding）

- 手持**末地烛**右键成年动物，立即在该动物身边生成一只**同物种幼崽**，并伴随大量爱心粒子。
- 每只动物有 10 秒催生冷却，无法对幼崽或已绝育的动物使用。
- 首次使用末地烛催生动物，解锁成就 **「种公！」（Stud!）**。

###  绝育与恢复系统（Neuter & Restore）

- **潜行 + 剪刀**右键动物：消耗剪刀耐久、掉落 2 个鸡蛋、扣除 0.5 点生命，为该动物打上绝育标记。
- 被绝育的动物**无法再繁殖**（幼崽出生会被拦截）。
- 手持**鸡蛋**右键已绝育动物：消耗 1 个鸡蛋，恢复其繁殖能力。

###  医学道具（Medical Supplies）

- **春药注射器（Aphrodisiac Syringe）**：右键任意生物，使其进入**发情**状态 5 分钟。
- **发情效果（Lust）**：效果持续期间，生物不断冒出爱心粒子，并主动寻找最近的成年同类：
  - **双方都发情**：紧贴在一起，每 6 秒繁殖一次；
  - **仅单方发情**：主动追逐伴侣，每 12 秒繁殖一次；
  - 冷却期间双方会强制保持靠近，距离过远甚至会直接贴脸传送（防止被原版 AI 打断）。
  - 对动物和村民均生效。
- **狗奶（Dog Milk）** / **生可乐（Raw Cola）**：收藏向稀有道具。

###  试管化学合成（Chemistry Synthesis）

- **试管（Test Tube）** 可以装入**溶液**（水桶 / 药水）和任意**固体物品**。
- 将特定组合放入试管即可触发**化学合成**，产出新物品。
- 配方存放在数据包中（`data/morebo/chemistry_recipes`），支持热重载（`/reload`），可自行扩展。
- 初始配方：**春药** = 试管 + 粉色染料 + 糖 + 金胡萝卜 + 溶液。

###  丰富的配置项

所有参数均可在游戏内配置界面（Mods → 本模组 → Config）或配置文件 `morebo-common.toml` 中调整：

| 配置项 | 说明 | 默认值 |
|---|---|---|
| `thrustStrength` | 繁殖推力力度 | 0.3 |
| `dropChance` | 繁殖时掉落水桶/牛奶桶概率 | 0.05 |
| `fatalDieChance` | 繁殖时"意外"掉落末地烛概率 | 0.005 |
| `detectionrange` | 亲吻触发检测距离 | 2.0 |
| `pfed` | 玩家在末地烛上触发掉落的概率比 | 0.5 |
